# CodingCamp--16November26-indri

A clean, minimal productivity dashboard built with HTML, CSS, and Vanilla JavaScript. All data is saved in the browser using Local Storage — no backend required.

## Features

- **Greeting** — Shows the current time, full date, and a greeting that changes with the time of day (morning / afternoon / evening).
- **Focus Timer** — A 25-minute countdown timer with Start, Stop, and Reset buttons.
- **To-Do List** — Add, edit (pencil icon or double-click), mark done, and delete tasks. Tasks persist across reloads via Local Storage.
- **Quick Links** — Save favorite websites as clickable buttons that open in a new tab. Links persist via Local Storage.

## How to Run

Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari). No build step or server needed.
